# Date Whisperer — Support

## Getting Started
1. Import `.pbiviz` into Power BI Desktop
2. Add visual to canvas (~200×40px)  
3. Drag a **Date** column into the **Date Field** bucket
4. Click the pill → select range → **✓ Apply Filter**

## Common Issues

**"Add a Date field" message** → Drag a date column into Date Field bucket

**Other visuals not filtering** → Check Edit Interactions → enable filter on each visual

**Dialog doesn't open in Service** → Admin: Tenant Settings → Allow visuals created using Power BI SDK
